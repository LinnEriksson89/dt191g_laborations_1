# Uppgift 1 - Razor Pages

Skapa en "Razor Pages"-applikation (dotnet new webapp).

Skapa minst tre undersidor, med navigering mellan dessa.

En av undersidorna skall ha en uppsättning med Razor-kod, där (som minimum) följande tekniker skall användas:

Variabler.
Array eller lista (till exempel en uppsättning med kurser).
Loop genom arrayen (ex foreach) för att skriva ut dess värden.
Villkorssats (exempelvis if/else).
